# ⚽ FIFA World Cup Analysis Dashboard — Excel

## 📌 Project Overview

An interactive Microsoft Excel dashboard developed to analyze FIFA World Cup
data from 1930 to 2014.

The dashboard transforms historical World Cup data into meaningful visual
insights covering team performance, wins, goals scored, matches played,
match outcomes, and attendance trends.

## 🎯 Objectives

- Analyze historical FIFA World Cup data
- Compare teams based on matches played
- Analyze country-wise World Cup wins
- Track goals and matches across different years
- Analyze attendance trends
- Present data through an interactive Excel dashboard

## 📊 Dashboard Features

- Top 10 Teams by Matches Played
- Top 10 Countries by Wins
- Goals Scored & Matches Played Over Years
- Total Goals Scored Over Years
- Match Outcome Distribution
- Attendance Over Years
- Year-wise filtering
- KPI Cards
- Interactive Excel visualizations
